☕ Café Finder API
A RESTful API that serves detailed information about cafés, including images, location, amenities like sockets, Wi-Fi, and toilets. Built for developers who want to integrate café discovery into their apps or services.

📦 Features
📍 Location-based café listings

🖼️ Image support for each café

🔌 Socket availability

📶 Wi-Fi status

🚻 Toilet access

🔁 RESTful architecture with standard HTTP methods
